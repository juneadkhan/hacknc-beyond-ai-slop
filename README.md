# Beyond AI Slop

HackNC 2026 · Junead Khan · 45-minute hands-on workshop

**[Open the workshop studio](https://juneadkhan.github.io/hacknc-beyond-ai-slop/)**

Redesign Friday, a fictional student money app. Create a design system with an AI chat, apply the CSS, and test whether a classmate can find the bills due before payday.

## Start here

- [Student exercise](STUDENT-GUIDE.md)
- [Browser slides](https://juneadkhan.github.io/hacknc-beyond-ai-slop/slides.html)

- [Facilitator guide](FACILITATOR.md)

The studio needs no account, installation, API key, or subscription. AI chat is separate and subject to its provider's account rules and limits. No AI service is bundled. Pair up or use the prepared CSS examples if access is unavailable.

## Work locally

Download or clone this repository. Open index.html for the studio, or starter-project/index.html for the editable app. Reference apps are in examples/. No npm install or backend is required. The offline ZIP includes the studio, references, guides and slides.

Changes are stored in your browser when local storage is available. Use Download my app and Download my guide before leaving. Nothing is uploaded by the studio. Pasted CSS runs in an isolated preview with network access disabled; do not paste sensitive data into AI chats.

The starter is deliberately authored to show inconsistent hierarchy and styling; it is not attributed to a particular model. Reference themes are prepared workshop examples. All financial data is fictional; this is not a financial product or advice.
