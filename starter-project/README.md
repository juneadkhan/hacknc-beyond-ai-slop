# Friday starter

Open index.html in a browser. Edit style.css, reload, and test the filters and bill details. No package install, server or API key is required.

If using an AI coding agent, give it DESIGN-SYSTEM.md and ask it to change style.css. Preserve the exact fixtures, dates, amounts, markup and interactions in app.js. All data is fictional. See the workshop student guide for the exercise and rubric.

Reference CSS is in reference-styles/. To try a reference, combine base.css with that reference CSS into style.css. Keep the base structural rules first and the reference rules after them. The studio handles this automatically.
